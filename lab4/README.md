### Что это за программа

Небольшой **рисовальник**: окно с панелью сверху и белым холстом снизу. Можно выбрать **цвет** (четыре квадрата) и **толщину линии** (кружки 1–5), рисовать мышью. Каждые **5 секунд** рисунок автоматически сохраняется в файл `lab4/saved_canvas.png`.

Интерфейс написан на **QML**, таймер и вызов сохранения — на **Python** (PyQt5).

### Как устроено

**QML (папка `qml_views/`):**

- `PaintRoot.qml` — главное окно, панель инструментов и `Canvas` с именем `canvas` (его ищет Python).
- `ColorSwatchRect.qml` / `StrokeWidthDot.qml` — кнопки выбора цвета и толщины.
- Рисование: `MouseArea` запоминает координаты, `onPaint` рисует линии через контекст `2d`.
- Метод `saveCanvas(path)` на холсте вызывает встроенное сохранение `Canvas` в PNG.

**Python:**

- `paint_entry.py` — запуск приложения, загрузка QML, регистрация `_backend` в контексте QML.
- `autosave_bridge.py` — `QTimer` раз в 5 с находит объект `canvas` через `findChild` и вызывает `saveCanvas` через `QMetaObject.invokeMethod`.
- `__init__.py` — пути к QML-модулям и плагинам Qt (нужно сделать до создания `QApplication`).

### Запуск

Из корня репозитория:

```powershell

```
