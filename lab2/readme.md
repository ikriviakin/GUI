### Архитектура и принцип работы

Приложение — валютный конвертер с **тремя** однострочными полями (`QLineEdit`): USD, RUB и EUR. Редактируется одно поле — значения в двух других обновляются сами. Реализация в `currency_converter.py`, класс **`FxTripleInputView`**.

Пересчёт идёт через **доллар США** как опорную валюту:

| Курс | Значение |
|------|----------|
| USD → RUB | 90 |
| USD → EUR | 0.92 |

### Логика работы

1. **Ввод и проверка.** На все поля повешен один `QDoubleValidator`: допустимы только неотрицательные числа, не больше 10 000 000, до двух знаков после запятой. Плейсхолдер — `0.00`.
2. **Сигнал `textChanged`.** Для каждого поля вызывается общий обработчик `_recalculate_from`: по типу источника (`_EditedField`) строка разбирается функцией `_parse_user_number` (запятая заменяется на точку), затем строится тройка USD/RUB/EUR.
3. **Защита от зацикливания.** Программная подстановка текста в «соседние» поля выполняется через `_write_silent`: перед `setText` включается `blockSignals(True)`, после — `blockSignals(False)`. Иначе обновление RUB/EUR снова вызвало бы `textChanged` и бесконечную цепочку пересчётов.
4. **Очистка.** Если пользователь полностью стёр активное поле, `_wipe_siblings` очищает два остальных (тоже без лишних сигналов).

**Направления пересчёта:**

- из **USD** — RUB и EUR умножением на курсы;
- из **RUB** — сначала USD (деление на 90), затем EUR через USD;
- из **EUR** — сначала USD (деление на 0.92), затем RUB через USD.

### Запуск

Из корня репозитория:

```powershell
python -m lab2.currency_converter
```
