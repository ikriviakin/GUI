### Назначение

Окно на PyQt5 для просмотра данных **SQLite**: подключаешь файл `.db`, выполняешь запросы — результат показывается в таблицах на вкладках.

При первом запуске в каталоге `lab3` создаётся учебная база `test_db_lab3.db` (таблицы users, products, orders) — её можно выбрать в диалоге подключения.

### Как пользоваться

1. Меню **Соединение → Set connection** — выбор файла базы.
2. После удачного подключения на **Tab 1** выводится содержимое `sqlite_master`, в выпадающем списке — имена таблиц.
3. **bt1** — сводка по объектам БД (Tab 2).
4. Выбор таблицы в списке — все строки таблицы (Tab 3).
5. **bt2** / **bt3** — DDL таблиц (Tab 4) и индексы, триггеры, представления (Tab 5).
6. **Close connection** — очистка таблиц на экране и закрытие соединения.
